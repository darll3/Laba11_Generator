📊 Student Report Card Generator
Настольное приложение на Python, созданное с использованием Tkinter, предназначенное для автоматизации учета успеваемости студентов, быстрого формирования отчетов, расчета среднего балла и сохранения всех данных в текстовый файл.

🎯 Назначение системы
Программа автоматизирует процесс ведения успеваемости студентов, позволяя пользователю быстро вводить данные, рассчитывать средний балл и сохранять результаты в файл.
