# 🎓 GUI-Based Student Report Card Generator

A Python desktop application built with Tkinter that collects student details and marks, validates input, computes total/percentage/grade, displays status messages, and appends each report to a file.

---

## 1. Название и краткое описание

**Student Report Card Generator** — это десктопное приложение на Python с графическим интерфейсом (Tkinter), предназначенное для сбора данных об успеваемости студентов, автоматического расчёта процента оценок, определения итоговой буквенной оценки (A–F) и сохранения отчётов в текстовый файл.
