# 📊 Student Report Card Generator

Приложение на Python, созданное с использованием Tkinter, предназначенное для автоматизации учета успеваемости студентов, быстрого формирования отчетов, расчета среднего балла и сохранения всех данных в текстовый файл.

---

## 🎯 Назначение системы

Программа автоматизирует процесс ведения успеваемости студентов, позволяя пользователю быстро вводить данные, рассчитывать средний балл и сохранять результаты в файл `report_card.txt`.

---

## 🎓 Шкала оценок

Оценка определяется по среднему баллу (процентному соотношению):

- **A** — средний балл >= 90
- **B** — средний балл 75–89
- **C** — средний балл 60–74
- **D** — средний балл 40–59
- **F** — средний балл < 40

## ⚙️ Установка

1. Перейдите в репозиторий с программой на GitHub;
2. Нажмите на кнопку **Code** в репозитории, далее нажмите **Download ZIP**;
3. Распакуйте архив в удобную папку.

---

## 🚀 Запуск

Для запуска программы дважды щелкните левой кнопкой мыши по файлу `report_card.py` в распакованной папке.  
Если графический интерфейс открылся без системных уведомлений об ошибках — значит, программа запущена и готова к работе.

---

## 📝 Основные сценарии использования

**Как создать отчет:**

1. Введите данные студента (имя, номер зачетной книжки, оценки) в соответствующие поля формы.
2. Нажмите кнопку **«Generate Report»**.
3. Появится сообщение об успешном добавлении записи в отчет.  
   Программа создаст файл `report_card.txt` с записью об успеваемости в папке с приложением.

**Как очистить данные:**

1. Нажмите на кнопку **«Clear»**.
2. Поля ввода станут пустыми и готовыми к вводу новых данных.

**Как добавить данные (накопление):**

1. Нажмите на кнопку **«Clear»**.
2. Введите данные для следующего студента.
3. Нажмите кнопку **«Generate Report»**.
4. Программа автоматически допишет новую запись в конец файла `report_card.txt`.

## ⚠️ Действия при нештатных ситуациях

**🚫 «Файл не найден»**  
*Причина:* запуск программы не из своей папки.  
*Решение:* запускайте программу строго из папки, где лежит `report_card.py`.

**❌ «Ошибка чтения CSV»**  
*Причина:* в поля оценок введены буквы или символы.  
*Решение:* убедитесь, что вводите только числа в поля оценок.


**📦 Отсутствие модуля `tkinter`**  
*Причина:* Tkinter не установлен в системе.  
*Решение:* установите tkinter командой `pip install tkinter`
